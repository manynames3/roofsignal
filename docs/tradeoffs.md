# Engineering Tradeoffs

| Decision                                   | Benefit                                                                         | Cost / next threshold                                                                                                                                                         |
| ------------------------------------------ | ------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Cloudflare SPA + optional AWS backend      | Public sample opens without cloud credentials; AWS data boundary is inspectable | Two release surfaces, explicit CORS/callbacks and manual configuration; no single atomic release                                                                              |
| One Python Lambda / Terraform root         | Short runtime path and small operational footprint                              | Shared IAM/blast radius, provider latency consumes invocation time; split ownership when workload/teams warrant it                                                            |
| Deterministic TypeScript scoring           | Rules and evidence are visible and testable                                     | Heuristic, browser-authored output; server validation is needed for authoritative records                                                                                     |
| Human-confirmed Gemini drafts              | Optional assistance retains rep control                                         | Provider cost/privacy/availability, no measured accuracy benchmark; manual evidence remains necessary                                                                         |
| DynamoDB JSON snapshots                    | On-demand persistence without database hosts                                    | Item ceiling, shallow updates, report-ID ordering and no pagination; no transactional CRM model                                                                               |
| Private direct S3 POST                     | Binary uploads bypass API and enforce a signed size/type policy                 | S3/report writes are not atomic; MIME is declared, not inspected; orphan/reference-aware cleanup is incomplete                                                                |
| Independent retention                      | Reused photos survive deletion of one report                                    | Lifecycle can outlive a deleted report or expire a photo used by a newer report; add report-owned objects or reference tracking before stronger erasure/availability promises |
| Company-wide reads / owner-admin mutations | Shared team visibility with scoped mutations                                    | Tenant isolation depends on application checks under one role; separate accounts/roles offer stronger boundaries at higher complexity                                         |
| Managed public endpoints, no VPC/NAT       | Avoids idle network infrastructure for managed-service calls                    | No private network isolation; auth, application checks and signed storage policies carry the boundary                                                                         |
| Manual reviewed AWS release                | No deploy credentials in validation CI                                          | No automated plan approval, canary, alias or tested rollback; team rollout needs protected state and release controls                                                         |
| Metadata logs + basic alarms               | Diagnosable requests without logging customer content                           | No distributed traces, dashboard, measured SLO or default alert recipient                                                                                                     |

[Five ADRs](adrs/README.md) record the accepted decisions. [Security](security.md), [cost](cost-model.md) and [runbook](runbook.md) describe the practical limits. These choices favor an inspectable work sample; they do not establish production scale or operational readiness by themselves.
